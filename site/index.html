install

free, nothing else needed

Runs on a computer. Open this page on one to install.

  1. Open Terminal: Launchpad › type Terminal › Enter.
  2. Paste this and press Enter:
    curl -fsSL https://raw.githubusercontent.com/laksh-ya/mashup-deck/main/install.sh | sh
  1. Open PowerShell: Start › type PowerShell › Enter.
  2. Paste this and press Enter:
    irm https://raw.githubusercontent.com/laksh-ya/mashup-deck/main/install.ps1 | iex
